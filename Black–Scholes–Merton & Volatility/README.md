# Black–Scholes–Merton & Volatility

This folder contains implementations and analysis of the Black–Scholes–Merton framework for European option pricing and historical volatility estimation, developed as part of **MA 374 — Financial Engineering**.

## Topics Covered

- Black–Scholes–Merton option pricing
- European call and put options
- Time-dependent option pricing
- Option price sensitivity to model parameters
- Historical volatility estimation
- Volatility annualization
- Option pricing using historical volatility
- Sensitivity of option prices to strike price
- Volatility and option-price behaviour across different historical data windows

## Labs

### Lab 08 — Black–Scholes–Merton Option Pricing

Implemented a program to compute European call and put option prices at arbitrary time points in the classical BSM framework.

The analysis includes:

- Computing call and put prices as functions of time and underlying asset price
- Plotting option prices for different time points
- Visualizing option prices in three dimensions
- Studying the sensitivity of call and put prices to model parameters
- Presenting the results using tables and two- and three-dimensional plots

### Lab 09 — Historical Volatility & BSM Pricing

Applied historical market data to estimate volatility and use it for BSM option pricing.

The analysis includes:

- Estimating historical volatility from different data windows
- Annualizing historical volatility using daily returns
- Pricing six-month European call and put options using the BSM model
- Studying option prices across different strike prices
- Examining how extending the historical estimation period affects volatility and option prices
- Plotting volatility and option prices against the corresponding historical data period
- Collecting market option-price data for NIFTY across different maturities and strike prices
