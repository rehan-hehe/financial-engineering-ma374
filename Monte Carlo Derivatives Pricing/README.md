# Monte Carlo Derivatives Pricing

This folder contains implementations of Monte Carlo methods for stochastic asset-price simulation and derivative pricing, developed as part of **MA 374 — Financial Engineering**.

## Topics Covered

- Geometric Brownian Motion (GBM)
- Real-world and risk-neutral simulation
- Monte Carlo simulation
- Asian option pricing
- Arithmetic-average payoff
- European call and put options
- Sensitivity analysis
- Variance reduction techniques
- Comparison of Monte Carlo pricing results

## Lab

### Lab 11 — Monte Carlo Pricing of Asian Options

Simulated asset-price paths under both real-world and risk-neutral measures and used Monte Carlo simulation to price six-month Asian options.

The analysis includes:

- Simulating multiple asset-price paths using GBM
- Comparing simulations under the real-world and risk-neutral measures
- Pricing arithmetic-average Asian call and put options using Monte Carlo simulation
- Studying the effect of different strike prices on option values
- Performing sensitivity analysis of the option prices
- Applying variance-reduction techniques to improve Monte Carlo pricing
- Comparing pricing results before and after variance reduction

## Key Concepts

**GBM → Risk-Neutral Simulation → Monte Carlo → Asian Options → Sensitivity Analysis → Variance Reduction**
