# Portfolio Optimization & CAPM

This folder contains implementations of modern portfolio theory and empirical asset-pricing methods developed as part of **MA 374 — Financial Engineering**.

The work progresses from theoretical portfolio optimization using a small set of assets to empirical analysis using BSE and NSE market data.

## Topics Covered

- Markowitz portfolio optimization
- Mean-variance analysis
- Efficient frontier
- Minimum-variance portfolios
- Portfolio risk and return
- Short-sale constraints
- Capital Market Line (CML)
- Security Market Line (SML)
- Market portfolio
- CAPM and beta estimation
- Empirical analysis using BSE and NSE data

## Labs

### Lab 04 — Markowitz Portfolio Optimization & CAPM

Constructed and analyzed portfolios using given expected returns and covariance data for three assets.

The analysis includes:

- Constructing and plotting the Markowitz efficient frontier
- Computing portfolio weights, expected returns, and risk
- Finding maximum and minimum returns for a specified risk level
- Finding the minimum-risk portfolio for a specified return
- Determining the market portfolio using a risk-free asset
- Constructing and plotting the Capital Market Line
- Finding portfolios combining risky and risk-free assets
- Extending the analysis to 10 real stocks using market data
- Constructing the Security Market Line for the individual assets

### Lab 05 — Short Sales & Empirical CAPM

Extended the portfolio optimization framework by imposing a **no-short-selling constraint** and analyzing its effect on the feasible portfolio region and minimum-variance curve.

The analysis includes:

- Constructing the feasible region under no-short-sale constraints
- Computing the minimum-variance curve and efficient frontier
- Comparing portfolios formed using different combinations of securities
- Analyzing the weights along the minimum-variance curve
- Using BSE and NSE index data as market portfolios
- Comparing stocks included and not included in the respective indices
- Estimating and comparing security betas
- Using the Security Market Line to draw inferences about individual securities

## Key Concepts

**Mean-Variance Optimization → Efficient Frontier → Minimum Variance → Market Portfolio → CML → CAPM → Beta → SML**
