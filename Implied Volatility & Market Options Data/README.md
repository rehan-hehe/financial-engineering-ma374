# Implied Volatility & Market Options Data

This folder contains the analysis of market option prices and implied volatility using the Black–Scholes–Merton framework, developed as part of **MA 374 — Financial Engineering**.

## Topics Covered

- Market option-price data
- NIFTY index options
- Stock options
- Option prices across strikes and maturities
- Implied volatility
- Numerical root-finding
- Newton–Raphson method
- Historical volatility
- Comparison of implied and historical volatility
- Volatility surfaces

## Lab

### Lab 10 — Implied Volatility & Volatility Analysis

Collected and analyzed market option-price data for NIFTY and selected NIFTY constituent stocks from different industries.

The analysis includes:

- Collecting closing prices of calls and puts across different maturities and strike prices
- Visualizing option prices as functions of strike price and maturity
- Constructing three-dimensional option-price surfaces
- Computing implied volatility from observed market option prices using the BSM model
- Applying numerical root-finding methods such as Newton–Raphson to obtain implied volatility
- Constructing three-dimensional implied-volatility surfaces
- Examining implied volatility as a function of strike price and maturity
- Estimating historical volatility over periods corresponding to option maturities
- Comparing historical and implied volatility using tabular and graphical analysis

## Key Concepts

**Market Option Data → BSM → Numerical Root Finding → Implied Volatility → Historical Volatility → Volatility Surface**
